## Description and Usage 

Task CLI - A simple Task Management Tool  
 - **usage: task-cli [command] [parameters]**  
     - commands:
         - help - show this help message
         - add (description) - add task with the description
         - update (id) (description) - update the description of a task
         - delete (id) - delete task with given id
         - mark-in-progress (id) - mark the specified task as in progress
         - mark-done (id) - mark the task as done
         - list [status] - list all (without parameter) or by status
            - status: todo/in-progress/done'''
